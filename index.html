What an ODE is — and what the unknown actually is

Core · NTU Part 1 syllabus

A differential equation contains an unknown function and one or more of its derivatives. In this course the typical unknown is y=y(x). The independent variable is x; y′=dydx is the rate at which the function changes.

A first-order ODE contains y′ but no higher derivative. The order is the highest derivative present.

First-order ODE method checklist

Use this order when you meet a new equation.

1 · Separable?Can you write \(y' = F(x)G(y)\)? Separate, integrate, then check any values of \(y\) you divided by.
2 · Homogeneous?If \(M\) and \(N\) have the same homogeneous degree, use \(y = ux\). A scaling guess \(y = ux^\alpha\) can sometimes help beyond that.
3 · Exact?For \(M \,dx + N \,dy = 0\), test \(M_{y} = N_{x}\). If true, reconstruct a potential \(\phi (x,y)\).
4 · Non-exact but fixable?Compute \(M_{y} - N_{x}\) and test for an integrating factor depending only on \(x\), only on \(y\), or on \(x+y\).
5 · Linear?Put it in \(y' + p(x)y = q(x)\) first. Then \(I=e^{\int p \,dx}\) and the left becomes \((Iy)'\).
6 · Named special form?Bernoulli → linear using \(\nu =y^{1-\alpha }\). Riccati → linear if one solution \(S(x)\) is known. Clairaut → line family plus possible singular envelope.
7 · IVP?Find the general solution first, then use the initial condition to determine the constant.
